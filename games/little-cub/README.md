# Little Cub — A Tiny Bear Life

**Status: rebuild specification; implementation not yet imported into this repository.**

Little Cub is a personal, offline-capable browser game about an adorable brown bear cub living with Mama and a littermate. The surface is warm, cozy, and naturalistic; the simulation can also become violent, frightening, and tragic because the characters have autonomy and consequences.

The current standalone HTML prototype is version 0.2, maintained outside this repository. Its small JavaScript game loop and automated mock-environment tests are a baseline to audit, not a verified production game. Do not claim its visuals, actual mouse/keyboard behavior, or sustained play have been certified until they are tested in a real browser.
